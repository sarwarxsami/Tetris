# Tetris

A Tetris-style falling-block game written in **C** using the **[raylib](https://www.raylib.com/)** graphics library. It was built during my first term break at BUET as a way to practise implementing game logic from scratch: piece rotation, collision detection, line clearing, scoring and a simple leaderboard.

## Features

- **7 tetrominoes** (O, L, I, J, Z, T, S), each stored as a 4×4 matrix and drawn in its own color
- **Rotation** by transposing the 4×4 matrix and then reversing its rows
- **Collision detection** against the floor and against blocks that have already landed
- **Line clearing**: full rows are removed and the rows above shift down
- **Scoring and speed-up**: each cleared line adds 1 point and makes pieces fall faster
- **Game over** when a piece locks at the top of the board
- **Multiple screens**: a splash screen, a main menu, player-name entry, the game, a score screen and a leaderboard
- **Leaderboard**: player names and scores are saved to `file.txt` and shown from the menu

## Controls

| Key / Action | Effect |
|---|---|
| `←` / `→` | Move the piece left / right |
| `Space` | Rotate the piece |
| `Backspace` (in game) | End the current game |
| `Enter` | Continue past the splash, name-entry and score screens |
| Mouse click | Choose menu options (Play, Leaderboard, Back) |

## Board and window

- The playfield is a **20 × 30** grid of 30 px cells (600 × 900 px).
- The final version uses a **1000 × 900** window, with a side panel on the right that shows the score and level.
- The game runs at **20 FPS**.

## Building and running

1. Install [raylib](https://github.com/raysan5/raylib) (for example `sudo apt install libraylib-dev`, `brew install raylib`, or the Windows installer, which bundles a MinGW compiler).
2. Compile:

   ```bash
   # Linux
   gcc tetris.c -o tetris -lraylib -lGL -lm -lpthread -ldl -lrt -lX11

   # macOS
   gcc tetris.c -o tetris -lraylib -framework OpenGL -framework Cocoa -framework IOKit -framework CoreVideo

   # Windows (MinGW)
   gcc tetris.c -o tetris.exe -lraylib -lopengl32 -lgdi32 -lwinmm
   ```

3. Run `./tetris` from a folder that contains the image and data files listed below.

### Required assets (not in this repository)

`tetris.c` loads five background images and a leaderboard file from the working directory:

| File | Used for |
|---|---|
| `1.png` | Splash screen |
| `2.png` | Game-over / score screen |
| `3.png` | Main menu |
| `4.png` | In-game side panel (score and level) |
| `5.png` | Player-name entry screen |
| `file.txt` | Leaderboard (created and appended to by the game) |

You need to supply these images (1000 × 900 for full screens, 400 × 900 for the side panel) before running the final version. `main.c` does not need any assets.

## Known limitations

- Pieces come in a fixed cycle rather than in random order; only the starting column is random.
- Rotation does not check for walls or collisions, so a rotated piece can overlap other blocks or go past the edge.
- Only one full line is detected per frame.
